# Workmap 功能文档

本文说明 Workmap 能做什么、怎么用、在 md 里存成什么样。实现细节见 [设计文档](design.md)。

## 1. 基本概念

| 概念 | 说明 |
| --- | --- |
| 时段笔记 | 一期一个 md 文件，路径为 `年/月/开始-结束.md`，例如 `2026/12/1-10.md`。开始和结束在同一个月，日期不补零（月份文件夹可以补零）。 |
| 周期任务 | 这一期要推进的主线，写在笔记顶部的 `## 周期任务` 小节。 |
| 每日任务 | 某一天要做的事，写在 `## DD`（某日）小节里。可以挂在某个周期任务下面。 |
| 四象限 | 每日任务按「重要 / 紧急」分进四个列表：马上做、排时间做、尽快处理、少做或不做。 |
| 日程 | 当天的时段（默认 07-09、09-11 …），把任务排进去。 |
| 本期笔记 | 学习笔记、会议记录这类长内容。每篇是单独的 md 文件，放在这一期的文件夹里（`2026/12/1-10/`），时段笔记里只留链接。 |
| AI 回顾 / 出题 | 通过 DMXAPI 调用大模型，根据本期的任务和笔记写复盘、出复习题，结果也存成本期笔记。 |
| 工作助理 | 右侧边栏里的对话面板：今日简报、随时提问，还能建议改动，你确认后才写进笔记。 |

视图默认跟随「今天」：自动找到包含今天的时段笔记，显示今天的任务。

## 2. 笔记格式

一份时段笔记大致如下：

```markdown
[🧭 打开 Workmap](obsidian://workmap)

## 周期任务

- [ ] 论文返修 ★★★ 📅 2026-12-02 %%id:pfubl%%
  时间紧，先回审稿人 2
- [ ] 行业调研 ★ %%id:pq3k9%%
- [x] 整理技术报告

## 本期笔记

- [[2026/12/1-10/控制回路学习笔记|控制回路学习笔记]]
- [[2026/12/1-10/AI 回顾 12-10 2130|AI 回顾 12-10 2130]]

---

## 19

- [ ] 回复审稿意见 1-3 %%p:pfubl%% %%t:09-11%% %%c:2026-12-17%% %%m:75,25%%
- [/] 写综述 %%m:25,25%%
- [-] 订会议室（不用了） %%m:75,75%%
- [ ] 随手记下的事

## 18

- [x] 列返修清单 %%p:pfubl%% %%m:75,25%%
- [>] 回复审稿意见 1-3 %%p:pfubl%% %%m:75,25%%
```

规则：

- `## 周期任务` 到第一条 `---` 或下一个一、二级标题为止，是周期任务区。旧名 `## 四象限` 也能识别。周期任务在视图里的顺序就是它们在这里的顺序。
- `## 本期笔记` 放在周期任务后面、`---` 前面，每行一个笔记链接。没有这一节时，第一次新建笔记会自动加上。
- `---` 之后每一天一个 `## DD` 小节，新的一天插在最上面。
- 任务行是标准的 `- [ ]` / `- [x]`，所以 Obsidian 自带的任务功能照常可用。另外认 `- [/]`（进行中）和 `- [-]`（已取消），和 Tasks 插件的写法一致。
- 不要把长篇内容直接粘贴在 `---` 和天的小节之间：笔记里的 `#`、`##` 标题会打断时段笔记的结构。真这么做了，视图顶部会提示，一键就能整理成本期笔记（见 4.「本期笔记」）。
- 下面这些标记都可以手写，插件也会自动维护：

| 标记 | 含义 |
| --- | --- |
| `★` / `★★` / `★★★` | 星标：一般 / 重要 / 最重要。老格式 `**加粗**` 按三星读取。 |
| `📅 2026-12-02` | 截止日期 |
| `%%id:pxxxx%%` | 周期任务的编号，用于关联每日任务 |
| `%%p:pxxxx%%` | 每日任务属于哪个周期任务 |
| `%%t:09-11%%` | 排进了哪个日程时段 |
| `%%c:2026-12-17%%` | 这件事最初安排在哪天。顺延时自动写上，用来显示「已拖 N 天」 |
| `%%m:x,y%%` | 在四象限里的位置（见下） |
| 任务下的缩进行 | 备注，支持 Markdown |
| `- [/]` / `- [-]` | 进行中 / 已取消。已取消的不顺延，也不计入进度 |
| `- [>]` | 已顺延到其他日期的任务 |

0.6.0 起不再有每日习惯。以前笔记里的 `习惯：✅…` 行会原样保留，插件不再读写它们。

`%%m:x,y%%` 的意思：x > 50 算紧急，y < 50 算重要。在同一个象限里，按 y 从小到大排序。没有 `%%m%%` 的任务（比如在笔记里直接手写的）会出现在「待放置」里。

在实时预览模式下，`%%…%%` 元数据会被隐藏，笔记看起来更干净；切到源码模式能看到全部内容。

## 3. 界面一览（从上到下）

1. **顶部**：日期、星期、「今天」标记，以及本期进度条（第几天、还剩几天，竖线标出当前查看的日期）。右侧有：
   - 前一天 / 后一天按钮；不在今天时，中间多一个「回到今天」；
   - 切换时段的下拉框，第一项是「本期 · M/起–止」；
   - 打开笔记、新建下一期。
2. **顺延提示**（仅在有任务顺延到今天时出现）：说明有几项任务顺延了过来，可以「查看 / 收起」，也可以点「知道了」关掉。展开后，每一项可以「放回待放置」或删除。
3. **周期任务**：卡片网格。每张卡片包括：
   - 勾选圈、星标和重要程度文字（未标星时，鼠标移上去才显示星星）；卡片左边有一条色条：最重要红色、重要橙色、一般蓝色；没做完的最重要主线有一道沿边框流动的光和呼吸光晕，重要主线只有较淡的慢呼吸（跟随「趣味动画」开关）；
   - 截止倒计时（3 天内显示橙色，今天、明天或已过期显示红色）；
   - 标题和备注（最多显示 3 行）；
   - 进度条（关联的每日任务完成了几个），以及今天有几项。

   卡片顺序：未完成在前，已完成在后；同一组里按笔记里的顺序，拖动卡片就能调整。
5. **今日任务**：标题行有完成数和「隐藏已完成」开关，下面是输入栏。
   - 输入后回车，就会把任务加到选中的象限，排在该象限末尾。
   - 可以先选一个周期任务，让新任务挂在它下面。
6. **四象限 + 日程**：
   - 左边是 2×2 的象限列表，左侧和底部有「重要 / 紧急」坐标轴。
   - 右边是日程时段，当前时段用红线标出。
7. **待放置**：还没有象限位置的每日任务。
8. **本期笔记**：每篇笔记一张卡片，显示标题、开头几行、修改日期和字数。标题行右边有「AI 出题」「AI 回顾」「新建」。
9. **操作提示**：可以点 × 关掉，之后不再显示。

## 4. 操作

### 周期任务

| 操作 | 方式 |
| --- | --- |
| 新建 | 「周期任务」标题右侧的「新建」：填写内容、星标、截止日期、备注 |
| 完成 / 取消 | 点勾选圈 |
| 改星标 | 点星星，或者在右键菜单里选 |
| 调整顺序 | 在周期任务区里拖动卡片，蓝色竖线标出放下的位置；拖到一半按 Esc 取消。改的是笔记里任务块（连同备注）的顺序 |
| 进行中 / 已取消 | 右键 →「标记为进行中」「标记为已取消」「恢复为未开始」 |
| 编辑 | 双击卡片，或右键 →「编辑」 |
| 今天做一部分 | 把卡片拖进某个象限，或右键 →「今天做一部分…」：输入今天的子任务，它会挂在这个周期任务下面 |
| 定位到笔记 | 右键 →「在笔记中定位」 |
| 删除 | 右键 →「删除」（可以撤销） |

截止日期用日历下拉选择。快捷选项有今天、明天、周五（今天是周五时显示为「下周五」）、下周一、一周后、本期结束；日历中本期最后一天会做标记。点日历外面会收起日历。笔记里手写了不存在的日期（比如 `2026-02-30`）时，会显示「日期无效」，重新选一个就好。

### 每日任务

| 操作 | 方式 |
| --- | --- |
| 添加 | 输入栏回车；或者鼠标移到象限标题上，点 `+`，输入栏会切到这个象限 |
| 完成 | 点勾选圈（底部出现提示，可以撤销） |
| 调整顺序 | 在象限里上下拖，蓝色插入线标出放下的位置；拖到一半按 Esc 取消 |
| 换象限 | 拖到别的象限；或右键 →「移到「…」」 |
| 排进日程 | 拖到右侧某个时段；或双击编辑，选择时段 |
| 移出日程 | 鼠标移到日程里的条目上，点 × |
| 移回待放置 | 右键 →「移回待放置」 |
| 进行中 / 已取消 | 右键 →「标记为进行中」「标记为已取消」「恢复为未开始」 |
| 编辑 | 双击：内容、备注、归属的周期任务、时段、截止日期 |
| 删除 | 右键 →「删除」（可以撤销） |

点日程里的某个时段会打开一个小窗口。可以新写一个任务（并选择象限），也可以从当天还没排进日程的任务里选一个。

### 撤销

删除、完成、拖动、编辑等改动都会记录下来，最多 30 步。撤销有三种方式：

- 底部提示条上的「撤销」（5 秒后自动消失）；
- 视图里按 ⌘Z（Windows 上是 Ctrl+Z）；
- 命令「撤销上一步操作」。

如果文件在别处被改过（比如你在编辑器里改了笔记），这一步就不会撤销，以免覆盖你的修改。自动顺延或「整理成本期笔记」改动过这份笔记时也一样，提示里会说明原因。

### 自动顺延

视图停在「今天」时，会检查本期和上一期里今天之前的每日任务；在设置里填了「顺延起点」的话，改为检查起点之后的各期，早于起点的任务一律不动。没完成的（包括「进行中」的）会：

1. 复制到今天的小节，并清掉原来的日程时段（备注、象限、所属周期任务都保留），同时记下最初安排的日期 `%%c:…%%`；
2. 原来那一行改为 `- [>]`，表示已顺延，以后不会再被处理。如果在设置里把「顺延后的原任务」改成「删掉」，原来那一行连同备注会直接删除，笔记更干净。

顺延来的任务会显示 **「已拖 N 天」**：1–2 天橙色，3–6 天深橙，7 天以上红底并轻轻闪动。鼠标停在上面能看到最初安排的日期。0.6.0 之前顺延的任务没有 `%%c%%`，插件会顺着前几天同名的 `[>]` 往回找，找到最早那天。顶部也会出现顺延提示。

### 新建一期

点「新建下一期」或运行命令，默认从本期结束的第二天开始（如果后面几期已经建好，就跳到它们之后），到 10 日、20 日或月末结束，不会和已有的期重叠。日期有问题时（跨月、结束早于开始、和已有的期重叠），窗口底部的预览会直接变红说明原因。新建时可以勾选「把上一期没完成的周期任务移过来」：

- 勾选后，这些任务（连同备注）会从旧笔记移到新笔记；
- 如果上一期还没结束（提前建下一期），现在不会动它：等到新一期开始那天第一次打开 Workmap 时，再把那时还没完成的周期任务移过去。新一期的周期任务区会提示这一点；
- 每日任务不需要迁移，它们会自动顺延。

新笔记的内容来自库里的 `tools/period-template.md`（如果没有这个文件，就用内置模板）。模板支持两个占位符：

- `{{tasks}}`：迁移过来的周期任务；
- `{{day}}`：第一天的日期。

模板里没写 `{{tasks}}` 也没关系：迁移的任务会放在 `## 周期任务` 下面，不会丢。

### 本期笔记

学习笔记、会议记录、读书摘录这类长内容，单独存成文件，放在这一期的文件夹里，比如 `2026/11/18-30.md` 这一期的笔记放在 `2026/11/18-30/`。时段笔记里只在 `## 本期笔记` 下面留一行链接。这样笔记里的标题和分隔线不会打乱时段笔记，AI 回顾和出题也能读到它们。

| 操作 | 方式 |
| --- | --- |
| 新建 | 「本期笔记」右侧的「新建」，或命令「新建本期笔记」：输入标题，在新标签页打开 |
| 打开 | 点卡片在新标签页打开；按住 ⌘ / Ctrl 点击在右侧打开 |
| 根据一篇出题 | 右键 →「AI 根据这篇出题」 |
| 从列表移除 | 右键 →「从列表移除（不删文件）」 |
| 删除 | 右键 →「移到废纸篓」：进系统废纸篓，可以在访达里恢复 |
| 登记 | 手动放进本期文件夹、但没写进 `## 本期笔记` 的文件会带「未登记」标记，右键 →「登记到「本期笔记」」 |

**整理粘贴进来的内容。** 如果直接把一篇笔记粘贴进了时段笔记，也就是不属于周期任务、本期笔记或任何一天的内容，视图顶部会提示「笔记里有 N 段内容不属于任何小节」。点「整理成本期笔记」，每一段会挪到一个新文件里，文件名取这段内容的第一个标题，原文一字不改，时段笔记里换成链接。点「定位」可以先在编辑器里看看是哪一段。

### AI 回顾和出题

通过 [DMXAPI](https://doc.dmxapi.cn/) 调用大模型（OpenAI 兼容的 `/v1/chat/completions` 接口）。先在设置里填 API 密钥。

- **AI 回顾**：把本期的周期任务（重要程度、截止日期、进度、备注）、每天的任务（状态、象限、所属主线、拖了几天）和本期笔记整理成一份摘要交给模型，生成一份复盘：一句话总结、主线进展、时间花在哪了、拖延与卡点（每条带具体拆法）、这期学到了什么、下一期建议。
- **AI 出题**：根据本期笔记出 8–12 道复习题，由概念到应用，参考答案放在折叠的提示框里，先想再点开。也可以只针对某一篇笔记出题。

生成要半分钟到两分钟。结果存成本期笔记（`AI 回顾 11-26 2130.md`、`复习题 11-26 2131.md`），带 `workmap: ai-review` / `ai-quiz` 的属性，并自动打开。以前生成的回顾和复习题不会再喂给模型。

点这两个按钮时，本期的任务和笔记内容会发给 DMXAPI 和所选模型的提供方。

### 工作助理

点左侧栏的机器人图标、Workmap 顶部的机器人按钮，或运行命令「打开 / 收起工作助理」，右侧边栏会打开助理面板；面板开着时再点一次就收起右侧边栏。

- **顶栏**：选模型（Claude Sonnet 5.5 / DeepSeek V4.1 Flash / Gemini 4 Hydrogen）和推理强度（低 / 中 / 高，越高想得越久、越贵）；右边是历史对话和新对话。
- **今日简报**：点「生成」，总结今天和昨天的任务、主线进展、最近笔记的要点，以及今天最该先做的一件事。当天会缓存，点「刷新」重新生成。
- **对话**：边生成边显示。有思考过程的模型（DeepSeek、Sonnet 在高强度下）会显示可折叠的「思考过程」。每条回复下面显示模型、用的 token 数，Sonnet 还会显示费用。
- **快捷提问**：今天先做什么、总结昨天、拖延分析、拆解任务、考考我。
- **带上**：决定这轮把哪些内容给模型：今天、昨天的任务，本期主线，本期笔记。每次发消息都会重新读笔记。
- **建议的改动**：让它安排或拆分任务时，回复下面会出现改动卡片，比如新增任务、换象限、标完成 / 进行中 / 取消、排进日程、新增主线。点 ✓ 才执行，点 × 忽略，「全部确认」按顺序执行。只会改今天的任务；执行后在 Workmap 里按 ⌘Z 可以逐项撤销。
- **存档**：每段对话存成一篇 md，放在本期文件夹的 `对话/` 里，比如 `2026/11/18-30/对话/11-26 1400 今天先做什么.md`。这些对话不算本期笔记，也不会喂给 AI 回顾。

### 时区

顶部可以在**美国 / 香港 / 巴黎**之间切换，旁边显示该时区的当前时间。选中后，「今天」、进度条、截止倒计时、日程里的当前时段、日期选择器和自动顺延都按这个时区算。选择会保存。美国具体用哪个时区（东部、中部、山地、西部）在设置里选。

切换时区只改显示，不会写笔记。如果切换后「今天」往后跳了一天，没做完的任务先留在原来的日期，顶部会询问：

- **顺延到今天**：马上按正常规则顺延；
- **先不**：这次先不提示。到了该时区的下一天，自动顺延照常进行。

### 趣味动画

默认开启，可以在设置里关掉。系统开启了「减弱动态效果」时自动关闭。

- **完成反馈**：打勾时勾选圈弹一下，溅出几颗同色小粒子。当天的任务全部完成（至少 2 项）时，飘一阵彩带。
- **本期战绩卡**：最后一个周期任务完成时，周期任务区翻出一张战绩卡，显示完成了几条主线、每日任务完成数、有完成任务的天数、最长连续几天都有完成，以及提前了几天完成。只要本期周期任务全部完成，这张卡就一直显示。
- **「马上做」的火苗**：火焰图标随火势变化。没完成的任务越多，火越旺；有任务（或它所属的周期任务）今明两天截止，火势再加一级。最旺时会冒火星，象限顶部透出暖光。把这个象限清空，火苗会熄灭并冒烟，标题提示「火已扑灭」。
- **「少做或不做」**：清空时，咖啡杯冒热气。

### 星空背景

默认开启，可以在设置「星空背景」里关掉。开启后整个视图都换成同一套配色：深色模式是深空，页面背景是深蓝渐变，带几团缓慢漂移的星云和一闪一闪的星星，偶尔也有流星划过；顶部、周期任务卡片、输入框、本期笔记、日程、托盘和提示都是半透明的深蓝玻璃，日程里「现在」那条线会发光。浅色模式是黄昏，背景从淡紫过渡到落日的暖橙。撤销提示和弹窗也跟着换色。

四个象限各是一片天空：

- **每完成一个每日任务，就在它所在的象限点亮一颗星。** 统计的是本期里查看日（含）之前完成的任务。星星的位置由日期和任务内容决定，刷新、重启后都不会变；之后再完成别的任务，也不会挪动已有的星星。
- **星星的样子有含义**：颜色跟着象限；所属周期任务的星级越高，星星越大，三星的还会发出十字星芒；查看日当天完成的星星会闪烁，越早完成的越暗。
- **星座**：同一象限里、同一个周期任务下的星星，按完成顺序用虚线连起来。
- **悬停联动**：鼠标移到象限里的某一行，它的星星（如果已完成）会放大，所属主线的星座会变亮，并显示主线名字，其他星星变暗。
- **流星**：打勾时，一颗流星从勾选圈飞进象限，落在新星的位置亮起来。
- **银河**：一条柔和的银河从「少做或不做」左下角缓缓升起，弧过「尽快处理」顶部，从「马上做」右上角出去，绕开四个象限交汇的中心。它由薄雾、发光的河心、几道暗尘带和两千多颗细小的星组成，宽度沿途起伏，中段略微鼓起，十几颗亮星带星芒闪烁。每一期笔记的银河细节都不同。
- **深色模式是夜空**：深蓝底色，每个象限带一点自己颜色的星云，有微尘般的小星星。背景里的小星星一闪一闪，少数亮星带星芒；任务星星也会轻轻明暗变化。「少做或不做」角落挂着一弯月亮，大约每 8 秒划过一颗流星，长短、角度、速度各不相同。
- **浅色模式是黄昏**：上面两个象限是淡紫的高空，飘着几朵云，「排时间做」里有一颗长庚星；下面两个象限靠中间的地平线泛着落日的余晖。银河在黄昏里是一条淡淡的暖白光带。

星星分布在哪个象限，直接反映这一期的时间花在了哪里。切到往期笔记，可以看到当期的星空。

## 5. 命令

| 命令 | 作用 |
| --- | --- |
| 打开 Workmap | 打开（或切到）视图，也可以用 `obsidian://workmap` |

| AI 根据本期笔记出复习题 | 同上，出复习题 |

## 6. 设置

| 设置 | 说明 |
| --- | --- |
| 配色 | 跟随 Obsidian / 浅色 / 深色 |
| 美国时区 | 顶部选「美国」时使用的时区：东部、中部、山地、西部 |
| 界面字号 | 14 / 16 / 18 / 20 px |
| 顺延起点 | 早于这一天的任务不再顺延，例如 `2026-11-18`。留空只看上一期和本期 |
| 顺延后的原任务 | 保留并标成 `[>]`（默认），或直接删掉 |
| 日程时段 | 用英文逗号分隔，例如 `07-09,09-11,14-16` |
| 趣味动画 | 完成反馈、彩带、战绩卡翻转、火苗动画、流星 |
| 星空背景 | 整个视图换成深空（深色）或黄昏（浅色）配色，象限里显示星空 |
| API 密钥 | DMXAPI 的令牌（`sk-…`），只存在本机的 `data.json` 里 |
| 模型 | 默认 Claude Sonnet 5.5；也可以选 Opus 5.5、Haiku 5.5、GPT-5.5、Gemini、DeepSeek、Qwen，或者填任意模型名 |
| 接口地址 | 默认 `https://www.dmxapi.cn/v1`；旁边的「测试连接」会发一条很短的请求 |

「隐藏已完成」、关掉的操作提示、当天的顺延记录也保存在 `data.json` 中。`data.json` 已在 `.gitignore` 里排除，密钥不会进仓库。
