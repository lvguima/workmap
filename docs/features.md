# Workmap 功能文档

本文说明 Workmap 能做什么、怎么用、在 md 里存成什么样。实现细节见 [设计文档](design.md)。

## 1. 基本概念

| 概念 | 说明 |
| --- | --- |
| 时段笔记 | 一期一个 md 文件，路径为 `年/月/开始-结束.md`，例如 `2026/12/1-10.md`。开始和结束在同一个月，日期不补零（月份文件夹可以补零）。 |
| 周期任务 | 这一期要推进的主线，写在笔记顶部的 `## 周期任务` 小节。 |
| 每日任务 | 某一天要做的事，写在 `## DD`（某日）小节里。可以挂在某个周期任务下面。 |
| 四象限 | 每日任务按「重要 / 紧急」分进四个列表：马上做、排时间做、尽快处理、少做或不做。 |
| 日程 | 当天的时段（默认 07-09、09-11 …），把任务排进去。 |
| 每日习惯 | 每天想坚持的事，在当天小节里打卡。 |

视图默认跟随「今天」：自动找到包含今天的时段笔记，显示今天的任务。

## 2. 笔记格式

一份时段笔记大致如下：

```markdown
[🧭 打开 Workmap](obsidian://workmap)

## 周期任务

- [ ] 论文返修 ★★★ 📅 2026-12-02 %%id:pfubl%%
  时间紧，先回审稿人 2
- [ ] 行业调研 ★ %%id:pq3k9%%
- [x] 整理技术报告

---

## 19

习惯：✅🏃 健身 ⬜📖 阅读

- [ ] 回复审稿意见 1-3 %%p:pfubl%% %%t:09-11%% %%m:75,25%%
- [ ] 订会议室 %%m:75,75%%
- [ ] 随手记下的事

## 18

- [x] 列返修清单 %%p:pfubl%% %%m:75,25%%
- [>] 没做完、已顺延的任务 %%m:25,25%%
```

规则：

- `## 周期任务` 到第一条 `---` 或下一个一、二级标题为止，是周期任务区。旧名 `## 四象限` 也能识别。
- `---` 之后每一天一个 `## DD` 小节，新的一天插在最上面。
- 任务行是标准的 `- [ ]` / `- [x]`，所以 Obsidian 自带的任务功能照常可用。
- 下面这些标记都可以手写，插件也会自动维护：

| 标记 | 含义 |
| --- | --- |
| `★` / `★★` / `★★★` | 星标：一般 / 重要 / 最重要。老格式 `**加粗**` 按三星读取。 |
| `📅 2026-12-02` | 截止日期 |
| `%%id:pxxxx%%` | 周期任务的编号，用于关联每日任务 |
| `%%p:pxxxx%%` | 每日任务属于哪个周期任务 |
| `%%t:09-11%%` | 排进了哪个日程时段 |
| `%%m:x,y%%` | 在四象限里的位置（见下） |
| 任务下的缩进行 | 备注，支持 Markdown |
| `习惯：✅名称 ⬜名称` | 当天的习惯打卡，名称可以带空格和 emoji |
| `- [>]` | 已顺延到其他日期的任务 |

`%%m:x,y%%` 的意思：x > 50 算紧急，y < 50 算重要。在同一个象限里，按 y 从小到大排序。没有 `%%m%%` 的任务（比如在笔记里直接手写的）会出现在「待放置」里。

在实时预览模式下，`%%…%%` 元数据会被隐藏，笔记看起来更干净；切到源码模式能看到全部内容。

## 3. 界面一览（从上到下）

1. **顶部**：日期、星期、「今天」标记，以及本期进度条（第几天、还剩几天，竖线标出当前查看的日期）。右侧有：
   - 前一天 / 后一天按钮；不在今天时，中间多一个「回到今天」；
   - 切换时段的下拉框，第一项是「本期 · M/起–止」；
   - 打开笔记、新建下一期。
2. **顺延提示**（仅在有任务顺延到今天时出现）：说明有几项任务顺延了过来，可以「查看 / 收起」，也可以点「知道了」关掉。展开后，每一项可以「放回待放置」或删除。
3. **周期任务**：卡片网格。每张卡片包括：
   - 勾选圈和星标（未标星时，鼠标移上去才显示星星）；
   - 截止倒计时（3 天内显示橙色，今天、明天或已过期显示红色）；
   - 标题和备注（最多显示 3 行）；
   - 进度条（关联的每日任务完成了几个），以及今天有几项。

   卡片排序：未完成在前，然后按星级从高到低，再按截止日期从近到远。
4. **今日习惯**：每个习惯是一个可点击的小块，点一下打卡或取消。连续 2 天以上会显示 🔥 和天数；鼠标停留时显示本期打卡次数。今天还没打卡时，连续天数算到昨天为止，不会因为还没打卡就清零。
5. **今日任务**：标题行有完成数和「隐藏已完成」开关，下面是输入栏。
   - 输入后回车，就会把任务加到选中的象限，排在该象限末尾。
   - 可以先选一个周期任务，让新任务挂在它下面。
6. **四象限 + 日程**：
   - 左边是 2×2 的象限列表，左侧和底部有「重要 / 紧急」坐标轴。
   - 右边是日程时段，当前时段用红线标出。
7. **待放置**：还没有象限位置的每日任务。
8. **操作提示**：可以点 × 关掉，之后不再显示。

## 4. 操作

### 周期任务

| 操作 | 方式 |
| --- | --- |
| 新建 | 「周期任务」标题右侧的「新建」：填写内容、星标、截止日期、备注 |
| 完成 / 取消 | 点勾选圈 |
| 改星标 | 点星星，或者在右键菜单里选 |
| 编辑 | 双击卡片，或右键 →「编辑」 |
| 今天做一部分 | 把卡片拖进某个象限，或右键 →「今天做一部分…」：输入今天的子任务，它会挂在这个周期任务下面 |
| 定位到笔记 | 右键 →「在笔记中定位」 |
| 删除 | 右键 →「删除」（可以撤销） |

截止日期用日历下拉选择。快捷选项有今天、明天、周五、下周一、一周后、本期结束；日历中本期最后一天会做标记。

### 每日任务

| 操作 | 方式 |
| --- | --- |
| 添加 | 输入栏回车；或者鼠标移到象限标题上，点 `+`，输入栏会切到这个象限 |
| 完成 | 点勾选圈（底部出现提示，可以撤销） |
| 调整顺序 | 在象限里上下拖，蓝色插入线标出放下的位置 |
| 换象限 | 拖到别的象限；或右键 →「移到「…」」 |
| 排进日程 | 拖到右侧某个时段；或双击编辑，选择时段 |
| 移出日程 | 鼠标移到日程里的条目上，点 × |
| 移回待放置 | 右键 →「移回待放置」 |
| 编辑 | 双击：内容、备注、归属的周期任务、时段、截止日期 |
| 删除 | 右键 →「删除」（可以撤销） |

点日程里的某个时段会打开一个小窗口。可以新写一个任务（并选择象限），也可以从当天还没排进日程的任务里选一个。

### 撤销

删除、完成、拖动、编辑等改动都会记录下来，最多 30 步。撤销有三种方式：

- 底部提示条上的「撤销」（5 秒后自动消失）；
- 视图里按 ⌘Z（Windows 上是 Ctrl+Z）；
- 命令「撤销上一步操作」。

如果文件在别处被改过（比如你在编辑器里改了笔记），这一步就不会撤销，以免覆盖你的修改。

### 自动顺延

视图停在「今天」时，会检查本期以及上一期里今天之前的每日任务。没完成的会：

1. 复制到今天的小节，并清掉原来的日程时段（备注、象限、所属周期任务都保留）；
2. 原来那一行改为 `- [>]`，表示已顺延，以后不会再被处理。

顺延来的任务带有「顺延」标签，顶部也会出现顺延提示。

### 新建一期

点「新建下一期」或运行命令，默认从本期结束的第二天开始，到 10 日、20 日或月末结束。新建时可以勾选「把上一期没完成的周期任务移过来」：

- 勾选后，这些任务（连同备注）会从旧笔记移到新笔记；
- 每日任务不需要迁移，它们会自动顺延。

新笔记的内容来自库里的 `tools/period-template.md`（如果没有这个文件，就用内置模板）。模板支持两个占位符：

- `{{tasks}}`：迁移过来的周期任务；
- `{{day}}`：第一天的日期。

### 每日习惯

在视图里点铅笔图标，或运行命令「编辑每日习惯」，可以增删习惯、调整顺序、改名。改名或删除只影响之后的打卡，笔记里以前的记录不会变。

### 趣味动画

默认开启，可以在设置里关掉。系统开启了「减弱动态效果」时自动关闭。

- **完成反馈**：打勾时勾选圈弹一下，溅出几颗同色小粒子。当天的任务全部完成（至少 2 项）时，飘一阵彩带。
- **本期战绩卡**：最后一个周期任务完成时，周期任务区翻出一张战绩卡，显示完成了几条主线、每日任务完成数、习惯打卡次数、最长连续打卡，以及提前了几天完成。只要本期周期任务全部完成，这张卡就一直显示。
- **「马上做」的火苗**：火焰图标随火势变化。没完成的任务越多，火越旺；有任务（或它所属的周期任务）今明两天截止，火势再加一级。最旺时会冒火星，象限顶部透出暖光。把这个象限清空，火苗会熄灭并冒烟，标题提示「火已扑灭」。
- **「少做或不做」**：清空时，咖啡杯冒热气。

### 星空背景

默认开启，可以在设置「星空背景」里关掉。四个象限各是一片天空：

- **每完成一个每日任务，就在它所在的象限点亮一颗星。** 统计的是本期里查看日（含）之前完成的任务。星星的位置由日期和任务内容决定，刷新、重启后都不会变；之后再完成别的任务，也不会挪动已有的星星。
- **星星的样子有含义**：颜色跟着象限；所属周期任务的星级越高，星星越大，三星的还会发出十字星芒；查看日当天完成的星星会闪烁，越早完成的越暗。
- **星座**：同一象限里、同一个周期任务下的星星，按完成顺序用虚线连起来。
- **悬停联动**：鼠标移到象限里的某一行，它的星星（如果已完成）会放大，所属主线的星座会变亮，并显示主线名字，其他星星变暗。
- **流星**：打勾时，一颗流星从勾选圈飞进象限，落在新星的位置亮起来。
- **星河**：一条细长弯曲的星河从「少做或不做」左侧流入，向下兜过「尽快处理」，再向上穿出「马上做」。河心是一道发光的光带，周围密布几百颗大小、颜色各异的小星，沿河有几处星团，十几颗亮星带星芒并闪烁。每一期笔记的星河星点分布都不同。
- **深色模式是夜空**：深蓝底色，每个象限带一点自己颜色的星云，有微尘般的小星星。「排时间做」里有一道淡淡的银河光带，「少做或不做」角落挂着一弯月亮，偶尔还会划过一颗流星。
- **浅色模式是黄昏**：上面两个象限是淡紫的高空，飘着几朵云，「排时间做」里有一颗长庚星；下面两个象限靠中间的地平线泛着落日的余晖。星河在黄昏里是一条暖白色的光带。

星星分布在哪个象限，直接反映这一期的时间花在了哪里。切到往期笔记，可以看到当期的星空。

## 5. 命令

| 命令 | 作用 |
| --- | --- |
| 打开 Workmap | 打开（或切到）视图，也可以用 `obsidian://workmap` |
| 新建下一期时段笔记 | 打开新建窗口 |
| 跳到今天的小节 | 在编辑器里打开本期笔记，定位到今天（没有今天的小节就新建一个） |
| 编辑每日习惯 | 打开习惯编辑窗口 |
| 撤销上一步操作 | 撤销 Workmap 做的最近一次修改 |

## 6. 设置

| 设置 | 说明 |
| --- | --- |
| 配色 | 跟随 Obsidian / 浅色 / 深色 |
| 界面字号 | 14 / 16 / 18 / 20 px |
| 每日习惯 | 打开编辑窗口 |
| 日程时段 | 用英文逗号分隔，例如 `07-09,09-11,14-16` |
| 趣味动画 | 完成反馈、彩带、战绩卡翻转、火苗动画、流星 |
| 星空背景 | 象限背景显示星空（深色）或黄昏（浅色） |

「隐藏已完成」、关掉的操作提示、当天的顺延记录也保存在 `data.json` 中。

## 7. 暂不支持 / 以后再做

- 今日小结和本期回顾：计划交给大模型，读取时段笔记（包括存进去的笔记内容）来生成总结，并出题帮助复习。
- 与 `month_plan`（Full Calendar 事件）打通。
- 键盘快捷键（新建、切换日期、回到今天）。
- 番茄钟（专注时长写回 md）。
- 跨月的一期：目前一期必须在同一个月内。
